# Known Issues

- HaMeR raw `joints.npy` outputs are local-ish and should not be used directly as final `P_exo`.
- The failed `P_exo_camera = joints + pred_cam_t_full` attempt was quarantined and is no longer treated as the final pipeline.
- Left-hand projection required a 2D bounding box mirror correction for hand depth rendering and final projection debug.
- Current `P_exo` is generated by depth-lifting 2D hand landmarks using `depth_scaled.npy` and `K_exo.npy`, not by direct HaMeR joint export.
- `P_ego` is not implemented yet.
- `P_ego` must use the same joint order and coordinate convention as `P_exo` when it is added.
